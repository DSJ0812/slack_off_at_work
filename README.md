# 小恐龙桌宠 · VPet 换装素材

把一只红 Q 版小恐龙做成 [VPet](https://github.com/LorisYounger/VPet) 桌面宠物的换装素材包。

## 特点

- **24 个动作**：待机、走动、吃饭、喝水、睡觉、洗澡、摸头、摸肚子、换装等
- **代码逐帧绘制**：大部分动画由 `src/dino_anim.py` 用 Python 直接绘制，不依赖现成素材
- **局部表情系统**：眼睛、嘴巴独立拆层，可叠加星星眼、爱心、汗滴、脸红等效果
- **AI 视频混合**：摸头、摸肚子等高表现力动作，用 AI 视频生成后经抠图、色彩校准、倾斜扭正处理

## 目录结构

```
.
├── assets/
│   └── dino_base.png          基础形象（1000×1000）

├── src/

│   ├── pack_full.py           铺素材到 VPet mod 目录（硬链接）
│   ├── pose_cut3.py           AI 视频抠图 + 色彩校准 + 倾斜扭正
│   ├── db4_cut.py             摸肚子动作的抠图配置
│   └── ...                    调参与校验工具
└── README.md
```

## 素材说明

**生成的动画素材约 3.97 GB（10,965 张 PNG），不纳入本仓库。**

获取方式：

1. 自行生成：安装依赖后运行 `src/dino_anim.py`（约 3~4 分钟）
2. 或联系作者获取打包版本

## 使用方法

1. 准备好 VPet 桌宠（[GitHub](https://github.com/LorisYounger/VPet) 或 Steam 版）
2. 把生成的素材铺到 `<VPet根目录>/mod/0000_core/pet/dino/`
3. 修改 `mod/0000_core/pet/vup.lps`，把 `path#` 指向 `dino`
4. **删除 `<VPet根目录>/cache/` 目录** —— VPet 的缓存不校验文件内容，不删会导致改动不生效
5. 重启 VPet
